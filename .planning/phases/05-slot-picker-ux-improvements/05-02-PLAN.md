<objective>
Add server-authoritative exact-duplicate-slot rejection to the poll-creation flow (SLOT-05): when a submitted poll contains two or more slots that are exact duplicates, reject the submission with an inline error on every duplicate row and the standard validation banner, re-rendered at HTTP 200 with all values preserved — never silently deduped, never partially saved.

Exact-match rule (per 05-CONTEXT.md SLOT-05, exact-match only — overlap detection is explicitly deferred): two all_day slots duplicate when they share the same date; two date_time slots duplicate when they share the same date AND start time AND end time. Cross-mode comparison does not apply (a poll is one mode, per Phase 1's locked poll_type decision).

Purpose: stop organizers from accidentally shipping a poll with a repeated option, and give a clear reason instead of a silent accept.
Output: a new markDuplicateSlots helper + duplicateSlotCopy constant in server.go, wired into handleCreatePoll, and a new create_dup_test.go with behavioral coverage.
