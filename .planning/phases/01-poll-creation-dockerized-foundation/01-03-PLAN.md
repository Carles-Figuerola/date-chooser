<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server -> browser (links page) | The admin token is rendered into the page and the URL; possession equals full future admin authority (Phase 4) |
| browser JS -> clipboard API | Copy is a client-side convenience; must degrade safely when the clipboard API is blocked (non-secure context / permission denied) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Information disclosure | admin token shown on links page / in URL | low | accept | Inherent to the link-based, no-accounts model (CONTEXT: token entropy is the protection; no rate limiting in v1). The page explicitly labels the admin link "keep this secret"; TLS is the operator's responsibility (CONTEXT: HTTPS termination is operator-owned) |
| T-01-07 | Cross-site scripting (Tampering) | links.html rendering of poll title + URLs | high | mitigate | Poll title and URLs are rendered through Go `html/template` auto-escaping; no `template.HTML`/raw interpolation. URLs are server-constructed from `r.Host` + tokens (tokens are base64url, no HTML-significant chars) |
| T-01-09 | Information disclosure | copy.js clipboard handling | low | accept | copy.js only writes the already-displayed URL to the clipboard on explicit user click; no new data exposure beyond what the page already shows |

ASVS level 1, block-on `high`: T-01-07 is the high item and is mitigated via `html/template` auto-escaping. No package-manager installs occur in this plan.
</threat_model>
